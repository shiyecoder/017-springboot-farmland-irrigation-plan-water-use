# 农田灌溉计划与用水统计系统 · 设计系统

## 1. 视觉方向

「运动钴蓝」专业业务系统。目标是**数据可读性、操作效率、状态辨识**。
不使用巨幅英文口号、装饰光效、悬浮球、大面积插画、过度渐变。
卡片圆角 6–8px；阴影只用于抽屉与弹窗；数字列启用等宽数字（`font-variant-numeric: tabular-nums`）。

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--primary` | `#0F3B5D` | 顶栏、主按钮、当前菜单、关键数字 |
| `--secondary` | `#2878B5` | 次级按钮、筛选选中态、普通图表系列 |
| `--accent` | `#245A7A` | 链接、信息提示、图表对比系列 |
| `--bg` | `#F4F8FB` | 主内容区背景 |

| `--success` | `#1F7653` | 已完成 / 已通过 / 正常 |
| `--danger` | `#B22B31` | 驳回、超时、异常、删除确认（仅小面积） |

图表色板（同含义跨页一致）：

## 3. 字体阶梯

系统中文无衬线：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`

| 层级 | 字号 / 行高 | 字重 | 场景 |
|---|---|---|---|
| 页面标题 | 20 / 28 | 600 | 内容区顶部 |
| 卡片标题 | 15 / 22 | 600 | 面板表头 |
| 正文 | 14 / 22 | 400 | 表格、表单 |
| 辅助 | 13 / 20 | 400 | 说明、时间戳 |
| 指标数字 | 28 / 34 | 600 等宽 | 看板 KPI |
| 表格数字 | 13 / 20 | 500 等宽 | 水量、金额、面积 |

## 4. 布局

- 桌面端：左侧菜单 **220px**（折叠 64px），顶部栏 **56px**，内容区自适应
- 内容区外边距 **24px**；卡片间距 16px
- 页面框架：`条件区（筛选）→ 业务摘要（可选）→ 数据区`
- 表单标签宽 **100–120px**，单列输入 **360–520px**，搜索下拉 **180–240px**
- 表格表头不写死宽度，按内容设 `min-width`，超宽横向滚动
- 断点 768px：侧栏转抽屉，表格转信息卡片，操作按钮固定底部安全区（≥44px）

## 5. 圆角 / 阴影 / 边框

- 圆角：卡片 8px，按钮 6px，输入框 6px，标签 4px，抽屉 12px（仅左侧圆角）
- 阴影：`0 8px 24px rgba(15,59,93,.12)` 仅用于 drawer / dialog / dropdown
- 边框：`1px solid var(--line)`；卡片不用阴影，靠边框区分层次

## 6. 状态语义

| 业务状态 | 标签底色 | 文字色 |
|---|---|---|
| 待审核 / 待排程 / 待执行 | `#EAF2F8` | `#245A7A` |
| 已安排 / 进行中 | `#E6F0F8` | `#2878B5` |
| 已完成 / 已通过 / 正常 | `#E7F3ED` | `#1F7653` |
| 已驳回 / 已中断 / 异常 | `#FBEAEA` | `#B22B31` |
| 超定额 / 待复核 | `#FBF0DF` | `#B4761E` |

## 7. 角色视觉区分

| 角色 | 入口风格 | 主色占比 | 特征 |
|---|---|---|---|
| 灌区管理员 admin | 后台管理（深色侧栏） | 主色重 | 侧栏 `#0F3B5D` 底、白色文字 |
| 调度员 dispatcher | 后台管理（浅色侧栏） | 主色中 | 侧栏白底、主色选中块 |
| 放水员 operator | 移动优先执行端 | 辅助色重 | 大按钮、卡片流、底部固定操作区 |
| 种植户 farmer | 门户/前台 | 辅助色 + 留白 | 顶部导航、内容卡片、无侧栏 |
